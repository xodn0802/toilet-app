# 화장실 찾기 앱(뿡) — 개발 명세

## 1. 프로젝트 개요

### 1.1 한 줄 정의
낯선 곳에서 급하게 화장실을 찾는 사람을 위한, 가까운 화장실 위치와 "실제로 쓸 만한지"(청결도·편의시설·이용조건)를 함께 알려주는 지도 앱.

### 1.2 문제 정의
- 급할 때 주변에 화장실이 어디 있는지 모른다.
- 지도 앱은 위치는 알려줘도 지금 열려있는지·깨끗한지·남녀공용인지는 모른다.
- 상가 화장실은 정보 자체가 없어 헛걸음하고, 결국 카페에 눈치보며 들어가거나 검색으로 헤맨다.

### 1.3 솔루션
| 문제 | 해결 기능 |
| --- | --- |
| 위치를 모름 | 공공데이터 기반 주변 화장실 지도 + 길찾기 |
| 상태를 모름 | 마커 상세에 필수 정보(남녀공용·변기 수·개방시간·편의시설) 즉시 표시 |
| 쓸 만한지 모름 | 사용자 크라우드소싱 리뷰(청결도 별점·사진·상태 태그) |
| 커피값 아까움 | 이용조건 태그(무료/개방/음료구매/유료) + 무료·개방 화장실 우선 노출 |

## 2. 핵심 사용자 (페르소나)
- **낯선 지역 이동이 잦은 사람** (여행·출장·외근): 주변에서 급히 화장실을 찾음
- **유아 동반 부모·노약자**: 기저귀 교환대·장애인 화장실 등 조건이 중요
- **재학생(캠퍼스)**: 처음 가는 건물에서 화장실 위치를 모름 — 확장 기능 대상

## 3. 핵심 기능 (Feature List)

### P0 — MVP 핵심
| # | 기능 | 설명 |
| --- | --- | --- |
| 1 | 지도 홈 + 현재 위치 | 지도 SDK에 현재 위치와 주변 화장실 마커 표시 |
| 2 | 공공데이터 연동 + 좌표 변환 | 전국공중화장실표준데이터 API 수집 → 주소를 지오코딩으로 좌표 변환 → DB 적재 |
| 3 | 마커 상세 | 화장실 탭 시 남녀공용 여부·변기 수·개방시간·편의시설 + 리뷰 열람 |
| 4 | 길찾기 | 선택한 화장실까지 경로 안내 (외부 지도앱 연동 또는 SDK 경로) |
| 5 | 리뷰 등록 | 청결도 별점 + 상태 태그(휴지·비누·비데 등) 등록 |
| 6 | 사진 업로드 | 리뷰에 사진 첨부 (최대 5장, 스토리지 저장) |
| 7 | 로그인 | 리뷰 작성자 구분용 소셜 로그인 |

### P1
| # | 기능 | 설명 |
| --- | --- | --- |
| 8 | 조건 필터 | 무료/개방/장애인/기저귀교환대/24시간 등으로 필터 |
| 9 | 이용조건 태그 | 무료·개방·음료구매·유료 표시, 무료·개방 화장실 우선 노출 |
| 10 | 즐겨찾기 | 자주 가는 화장실 저장 |

| 13 | 리뷰 신선도 표시 | 각 정보에 "최종 확인 시점" 노출 |

### P2 — 확장
- 사용자 화장실 직접 추가 (공공데이터에 없는 상가·카페 등)
- 캠퍼스 확장 (건물 → 층 구조로 실내 화장실 등록)
- 신고·삭제 (부적절 사진·오등록 대응)
- 혼잡 시간대 표시
- 친구 기반 공유·즐겨찾기 공유 (가설)

## 4. 화면 구성 (예상 스크린 리스트)
1. 온보딩/로그인
2. 지도 홈 — 주변 화장실 + 현재 위치
3. 화장실 상세 — 정보 + 리뷰 열람
4. 리뷰 작성 — 별점·상태 태그·사진
5. 길찾기 — 경로 화면
6. 필터
7. 검색
8. 즐겨찾기 목록
9. 마이페이지 — 내 리뷰·즐겨찾기
10. (확장) 화장실 추가 / 캠퍼스 건물·층 뷰

## 5. 기술 스택 제안
| 영역 | 기술 | 이유 |
| --- | --- | --- |
| 프론트엔드 | Next.js (React) + Tailwind | 빠른 개발, Vercel 무료 배포로 데모 링크 공유 쉬움 |
| 지도 | 카카오맵 지도 SDK (또는 네이버) | 국내 지도·마커·길찾기 지원, 주소→좌표 지오코딩 API 제공, 무료 |
| 백엔드 | Next.js API Routes | 프론트와 통합 배포, 서버리스로 빠르게 시작 |
| DB·인증·스토리지 | Supabase | DB(PostgreSQL) + 로그인 + 사진 저장을 한 번에 해결 |
| 공공데이터 | 공공데이터포털 전국공중화장실표준데이터 | 화장실 기본 데이터 무료 제공 |
| 배포 | Vercel | 프론트 + API 동시 배포, 빠른 데모 |
